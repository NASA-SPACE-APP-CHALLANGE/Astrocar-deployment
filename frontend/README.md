# 🚀 AstroCare — Frontend Client

> Space Mission Intelligence & Astronaut Health Monitoring System  
> Built with **React 19, Vite, TypeScript, Recharts, and Lucide Icons** for Team AlgoX.

---

## 💻 Development & Build Commands

```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Run TypeScript compilation and production build
npm run build

# Run linter
npm run lint

# Preview production build
npm run preview
```

## 🗺️ Page Architecture
- `/` — Mission Landing & Project Introduction
- `/login` — Astronaut vs Flight Surgeon Authentication Gateway
- `/dashboard` — Main Astronaut Health Dashboard
- `/dashboard/analytics` — Health Trend Analytics & Multi-temporal Recharts
- `/ai-insights` — AI Anomaly Intelligence & Spaceflight Countermeasures
- `/dashboard/alerts` — Alert Center & Clinical Triage
- `/dashboard/profile` — Astronaut Medical Baselines & Flight Day Log
- `/dashboard/reports` — Mission Health Reports & PDF/CSV Export
- `/dashboard/simulator` — Telemetry Simulator Studio
- `/mission-data` — Raw Telemetry Archive & Time Series
- `/dashboard/settings` — System Configuration & Contamination Slider
- `/about` — Team AlgoX Project Story & Challenge Context
